# Band Generator Project

## Description
The Band Generator Project is a simple application that generates random band names. This project is designed to help users come up with creative and unique band names for their musical endeavors.

## Features
- Generate random band names
- Simple and intuitive user interface

## Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/gustavo-rmontes/band-name-generator.git
    ```
2. Navigate to the project directory:
    ```bash
    cd band-generator-project
    ```
3. Install the dependencies:
    ```bash
    npm install
    ```

## Usage
1. Start the application:
    ```bash
    npm start
    ```
2. Open your web browser and navigate to `http://localhost:3000`
3. Enter your preferences and generate your band name!
